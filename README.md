# Pathstrider's Choice — Car Dealership Website

A multi-page front-end website for a fictional car dealership built as part of a 
Web Development course project at the University of Doha Science and Technology.

## Pages
- **Home** — Featured cars, customer reviews, and company overview
- **Products** — Full car catalogue with images and details
- **Contact** — Customer enquiry form
- **Subscribe** — Full registration form with client-side validation
- **FAQ** — Frequently asked questions

## Key Feature — Form Validation
The subscription page includes comprehensive client-side JavaScript validation covering:
- Full name, username (3–12 characters), and password matching
- Email format check and confirmation matching
- Qatar phone number format (+974 prefix, 8 digits)
- Age validation (1–99)
- Building number and street name validation
- Real-time inline error messages on each field

## Technologies
- HTML
- CSS (separate stylesheet per page)
- JavaScript (vanilla, no frameworks)
